# LinkForge 🔗

### A URL Shortening Service Built with .NET

LinkForge is a URL-shortening service designed to transform long URLs into compact, shareable links. The project focuses on clean backend architecture, reliable data persistence, API design, and the engineering practices required to build and deploy maintainable software.

Built with **C#, .NET 8, ASP.NET Core Minimal APIs, SQL Server, and Entity Framework Core**, LinkForge is an evolving portfolio project exploring the development of a production-oriented web service.

---

## ✨ Features

- **Short-link creation:** Generate a unique short code for a valid destination URL.
- **URL redirection:** Redirect users from a short link to its original destination.
- **Persistent storage:** Store short links and their metadata in SQL Server.
- **Unique short codes:** Generate random codes and check for existing
